# Stock Trading Platform

## CodeAlpha Internship – Task 2

### Project Description
A console-based Stock Trading Platform developed using Java as part of the CodeAlpha Java Programming Internship. This application simulates basic stock market operations, allowing users to view stocks, buy and sell shares, and manage their portfolios.

### Features
- Display available stocks and prices.
- Buy stocks.
- Sell stocks.
- Manage portfolio.
- Track transactions.
- Calculate total portfolio value.

### Technologies Used
- Java
- Object-Oriented Programming (OOP)
- VS Code

### Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- ArrayList
- Methods and Constructors

### How to Run
```bash
javac *.java
java Main
```
